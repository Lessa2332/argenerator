AR Генератор

Створіть навчальний AR-досвід без програмування. Відео, зображення, GIF, аудіо або посилання — один генератор для різних гаджетів.

Що хочете додати в AR?

Оберіть тип матеріалу. Генератор сам підготує потрібний режим.

Додайте відео

Завантажте файл або вставте пряме HTTPS-посилання.
Для файлу потрібне пряме HTTPS-посилання на ресурс.
AR-посилання можна відкрити на смартфоні, планшеті або іншому пристрої з камерою. Файли, завантажені через Worker, мають бути доступні за публічним HTTPS-посиланням.
